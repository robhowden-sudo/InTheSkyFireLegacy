# In The Sky Fire Legacy v2.7

Functionality/refinement pass based on the Windows Store layout and Android Native behavior.

- Flight cinematic restored: 1.15 s world acquisition hold followed by a 2 s smoothstep zoom/focus animation.
- Flight map controls now include Follow Target, Zoom to Path, Frame Route, World, Zoom − and Zoom +.
- Native-style geometric journey estimate added with confidence, remaining/from-origin/route/cross-track distances.
- Home marker always uses the saved Fire location.
- Weather history column uses weighted cards to consume available vertical space.
- Time summary card enlarged so local time/date/location text is not clipped.
- Moon image is clipped to the lunar disc with no black square; next New/Quarter/Full phase dates and times are shown.
- Sky View now plots local bright stars using true observer coordinates, approximate Sun/Moon positions, CelesTrak satellite predictions, aircraft, asteroids and comets.
- Satellite layer toggle added; Sector Scan refreshes satellites, small bodies and local sky objects.
- Main page panels use darker translucent blue-black surfaces so the star/nebula backdrop is visible across the app.
- Internal versionName/versionCode updated to 2.7/27.
