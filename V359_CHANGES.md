# v3.5.9 changes

- Added per-page selection for automatic page cycling in Settings > Sky / Dock.
- Radar, Flight, Weather, Time, Space, Sky View and Launches can each be included or excluded independently.
- Existing installs default all cycle pages to enabled, preserving prior behaviour.
- Cycling skips excluded pages even when the user manually visits one.
- If no pages are selected, automatic cycling remains idle rather than forcing a page.
- Version bumped to 3.5.9 / versionCode 59.
