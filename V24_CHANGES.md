# In The Sky Fire Legacy v2.4

Visual-parity pass based directly on the supplied Windows Store and Fire HD 10 screenshots.

- Radar scope size deliberately retained from v2.3.
- Windows-style nearest-contact table with column/row grid and tap-to-select.
- Radar selected-contact panel proportions/buttons matched more closely to Windows.
- Flight right column rebalanced and Windows journey/status strip restored.
- Weather hero typography rebuilt to match Windows hierarchy.
- Weather condition icon redrawn in the app instrument style rather than Android emoji.
- Weather local-conditions card rebuilt as the Windows-style top summary plus 3x2 data grid.
- Five-day forecast row sizing corrected so all five days fit.
- Weather history cards use Windows-style split panels with bar charts.
- Time summary strip reduced to Windows proportions; World Clocks remains collapsible with a subtle header.
- Space/Sky View/Launches panel ratios tightened to the Windows screenshots.
- Launch list styling changed from Android buttons to compact Windows-like list rows.
- Settings displayed as a centred instrument panel and controls tightened toward the Windows Settings window.
- Version updated to 2.4 in the UI/footer and Android package metadata.
