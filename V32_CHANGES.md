# In The Sky Fire Legacy v3.2

- Sky View planets now use representative real-world colours rather than a single cyan/blue colour.
- Added visible motion tracks for celestial objects and satellites in Sky View.
- Direction changes now refresh the Sky View title immediately.
- Weather five-day forecast now starts today, excludes yesterday, and has extra vertical allowance so the bottom outline remains visible.
- Five-day rows tightened slightly so all five forecast days fit inside the instrument frame.
