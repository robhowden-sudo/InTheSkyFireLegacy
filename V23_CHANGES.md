# In The Sky Fire Legacy v2.3

Windows Store visual-parity pass targeted specifically at the Fire HD 10 landscape display (1920 x 1200).

- Radar scope size intentionally retained from v2/v3 per user preference.
- Tighter Windows-style header, numbered navigation, footer, controls, padding and panel corners.
- Version identifier shown in persistent footer and Settings > About.
- Android versionName synchronized to 2.3.
- Weather dashboard tightened toward Windows Store proportions while retaining bar history charts.
- Time dashboard tightened; world clocks are collapsible and persistent.
- Added Windows-style decorative clock arcs and reduced oversized typography.
- Settings gains an About tab and more compact Windows-like spinner treatment.
- Existing v3 data fallbacks, radar/flight/sky handoff and launch resilience retained.
